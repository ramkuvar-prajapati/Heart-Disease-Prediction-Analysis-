# Heart Disease Diagnostic Analysis

## Project Overview

This project explores a medical dataset to identify critical risk factors associated with heart disease. Using Python for data exploration and visualization, the study focuses on detecting patterns that support early diagnosis and clinical decision-making. The key variables include age, cholesterol, chest pain type, resting blood pressure, maximum heart rate, and more.

## Objective

To analyze medical data and determine which health metrics are most strongly correlated with the presence of heart disease, ultimately supporting evidence-based diagnostics and prevention strategies.


## Dataset Features

- Age, gender, chest pain type
- Resting blood pressure, cholesterol levels
- Maximum heart rate, ECG results, oldpeak (ST depression)
- Number of major vessels, fasting blood sugar
- Heart disease target variable (1 = disease, 0 = no disease)


## Key Findings

- Individuals aged 50–60 have the highest heart disease prevalence.
- Chest pain type and maximum heart rate are strong predictors.
- High cholesterol paired with low heart rate correlates with increased risk.
- ECG abnormalities and high oldpeak values strongly relate to heart disease.
- Females tend to have higher median heart rates than males.
- Number of major vessels is inversely related to disease occurrence.


## Visualizations Used

- Age distribution by heart disease status
- ECG results vs age and target
- Cholesterol vs max heart rate
- Correlation heatmap
- Chest pain type vs target
- Max heart rate by gender
- Oldpeak vs target
- Number of major vessels vs target
- Fasting blood sugar vs age


## Tools & Technologies

- Language: Python
- Libraries: Pandas, Matplotlib, Seaborn
- Platform: Jupyter Notebook


## Conclusion

The analysis provides healthcare professionals with data-driven insights into key health indicators and their role in diagnosing heart disease. Features like chest pain type, maximum heart rate, and ECG results show high predictive value and can aid in building more accurate diagnostic models.
